# 光心偏心校正（几何图解）

> 配套 [[drill_scan_implementation.md]] §4③；物理参数：光心偏转盘轴 **5.5cm**
> 回归测试：`tests/test_servo_sweep.py::test_eccentric_offset_arc_reconstruction`
> 图中偏心距按 4× 放大便于观察（实际 5.5cm）

## 1. 物理问题：光心不在转盘轴上

![[attachments/eccentricity_geometry.svg]]

- 转盘绕**世界 z**（竖直）旋转；雷达光心 C 不在转盘轴上，偏 **5.5cm**（`--offset-x`）
- 转盘转 θ 时，光心 C 绕轴 O 做**圆弧运动**（半径 |d|）
- 同一世界点 P，在不同转盘角度测得的距离 r(θ) **不同**（0° 与 90° 差约 2·|d|），直接拼接会错位

## 2. 符号与公式（与测试逐行一致）

| 符号 | 含义 |
|------|------|
| p | 雷达系测量（极坐标→xyz 后，x 前/y 上/z 右） |
| d | 光心偏移，**雷达系常量** `(offset_x, 0, offset_z)` |
| T | `to_world` 轴重排 `(x,y,z)→(x,z,y)` |
| Rz(θ) | 绕世界 z（转盘轴）旋转 θ |
| C = Rz(θ)·T·d | 光心世界位置（圆弧运动） |

- **测量方程**：`p = T⁻¹ · Rz(−θ) · (P − C)`
- **正确重建**（先加 d 再旋转）：`P = Rz(θ) · T · (p + d)`
- **错误重建**（先减 d 再旋转）：`P′ = Rz(θ) · T · (p − d) = P − 2·Rz(θ)·T·d`

## 3. 正确公式：先加 d，再旋转

![[attachments/eccentricity_correct.svg]]

- 左图（θ=0°）：`p + d` 恰好**首尾相接**等于 P，直观可见
- 右图（θ=90°）：d 在雷达系内仍是常量，`T·(p′+d) = Rz(−θ)·P`，最后 Rz(θ) 转回世界系得 P
- 对应代码：`frame[:,0] += offset_x; frame[:,2] += offset_z` → `to_world` → `rotate_points(frame, 'z', angle)`

## 4. 错误公式：先减 d → "各圆柱面" bug

![[attachments/eccentricity_wrong.svg]]

![[attachments/eccentricity_cylinder.svg]]

- 错误公式下，每个世界点 P 被重建到**以 P 为圆心、半径 2|d| 的水平圆环**上
- θ 不同，重建点落在圆环不同位置 → 拼接后每点糊成圆环
- 竖直方向高度不变 → 3D 中每根钻杆糊成**圆柱面**（这就是历史上"各圆柱面"漂移 bug）
- 修复即回归测试：`P = Rz(θ)·T·(p + d)`（先加 d），5 个角度 θ∈{0,45,90,180,270} 全部精确回到 P

## 5. 数值示例（与测试同参数）

```
P = (2.0, 0, 0.5)     # 世界系墙上固定点
d = (0.055, 0, 0)     # 光心偏移，雷达系 x 前方 5.5cm
```

| θ | 正确重建 | 错误重建（漂移量） |
|---|---------|-------------------|
| 0°  | P（精确） | P − 2·d |
| 90° | P（精确） | P − 2·Rz(90°)·d |
| 180°| P（精确） | P + 2·d |
| 270°| P（精确） | P + 2·Rz(90°)·d |

漂移圆半径 = 2|d| = **0.11m**；`--offset-x/--offset-z` 即此处的 d 分量。
