# 雷达安装方式配置指南

> 目标：换雷达安装方式（正装/横装/任意倾斜）时**只改 YAML 配置文件，不改代码**。
> 实现：`scripts/install_config.py` + `configs/*.yaml` + `--install-config` 参数。

## 1. 核心思想：安装 = 两个独立自由度

雷达扫描数据（极坐标 → 雷达系 xyz）与安装方式**解耦**：

```
极坐标 → 雷达系xyz（scan_to_xy，纯几何，无安装假设）
       → 棱镜相位（mount_transform，绕雷达某轴旋转）
       → 安装姿态（to_world，雷达系 → 世界系轴映射）
       → 绕世界 z（转盘轴）旋转聚合 3D
```

| 变换 | 物理含义 | 需要配置什么 |
|------|---------|-------------|
| **mount**（棱镜相位） | LakiBeam 出厂 0° 参考与雷达 x 轴存在夹角，安装时绕雷达某轴旋转对齐 | `mount.axis` + `mount.angle_deg` |
| **to_world**（安装姿态） | 雷达系三轴相对世界系（转盘系）的指向 | `to_world.x/y/z`：世界系各轴取自雷达系哪个轴 |

## 2. 配置文件格式

```yaml
name: side-mount              # 配置名（仅标识）
description: 横装：雷达 x 下、y 左、z 前（默认）
mount:                        # 棱镜 0° 参考相位
  axis: z                     # 绕雷达系哪个轴旋转
  angle_deg: 90.0             # 旋转角度（度）
to_world:                     # 雷达系 → 世界系轴映射（可带负号）
  x: z                        # 世界 x 轴 = 雷达 z 轴
  y: y                        # 世界 y 轴 = 雷达 y 轴
  z: -x                       # 世界 z 轴 = -雷达 x 轴
turntable_axis: z             # 转盘旋转轴（世界系），默认 z

# 以下三项由 360° 自标定程序自动写入，也可手工微调。
tilt:                         # 转盘轴相对世界 z 轴的倾斜
  roll_deg: 0.0               # 绕世界 x 轴
  pitch_deg: 0.0              # 绕世界 y 轴
  yaw_deg: 0.0                # 通常保持 0（安装对齐）
lidar_tilt:                   # LiDAR 相对理想安装姿态的偏差
  roll_deg: 0.0               # 绕雷达 x 轴（全局偏航，程序固定为 0）
  pitch_deg: 0.0              # 绕雷达 y 轴（程序固定为 0）
  yaw_deg: 0.0                # 绕雷达 z 轴（可标定）
offset:                       # 光心相对转盘轴心的偏心（米，雷达系）
  y_m: 0.0
  z_m: 0.0
```

用法：`python scripts/servo_sweep_scan.py --install-config configs/xxx.yaml ...`

## 3. 如何确定你的安装配置（关键流程）

### 步骤 1：确定雷达系三轴的物理指向

LakiBeam 出厂坐标系：**x 前、y 左、z 上**（扫描弧在 x-y 水平面，0° 指 +x 前）。

你安装后，观察雷达壳体的三个轴分别指向世界哪个方向（世界系：z 竖直向上、x/y 水平）：

- 例如**横装**：x 指向下、y 指向左、z 指向前
- 例如**正装**：x 指向前、y 指向左、z 指向上

### 步骤 2：写 to_world（世界系三轴 = 雷达系哪个轴）

世界 z 必须**竖直**（= 转盘轴）。按"世界 x/y/z 各取自雷达系哪个轴"填：

- 横装（雷达 x 下、y 左、z 前）：
  - 世界 x（水平前）= 雷达 z（前）→ `x: z`
  - 世界 y（水平左）= 雷达 y（左）→ `y: y`
  - 世界 z（竖直上）= -雷达 x（下→上）→ `z: -x`
- 正装（雷达 x 前、y 左、z 上）：
  - 世界 x = 雷达 x（前）→ `x: x`；世界 y = 雷达 y → `y: y`；世界 z = 雷达 z → `z: z`

### 步骤 3：写 mount（棱镜 0° 参考相位）

默认横装：出厂 0° 指 +x（前），横装后 x 朝下，但实测单帧弧 0° 应指**水平**方向，
所以需要绕雷达 z 轴转 90° 对齐（`axis: z, angle_deg: 90`）。

判断方法：**实机单帧渲染**，若弧的 0° 指向世界竖直方向而不是水平方向，
说明棱镜相位没对齐，调整 `mount.angle_deg`（90 / -90 / 0 / 180）直到 0° 指向水平。

### 步骤 4：标定偏心

安装配置确定后，重新实测 `--offset-y / --offset-z`（光心相对转盘轴心偏移）。

## 4. 常见安装方式预设

| 配置 | 说明 | mount | to_world |
|------|------|-------|----------|
| `side-mount`（默认） | 横装：x 下/y 左/z 前 | 绕 z 90° | x←z, y←y, z←-x |
| `upright` | 正装（出厂姿态）：x 前/y 左/z 上 | 绕 z 0° | x←x, y←y, z←z |

## 5. 验证方法

1. **单帧弧方向**：0° 应指世界水平方向、90° 指世界竖直方向（横装时）
2. **完整重建**：转盘扫完后 3D 点云形状正确、无扭曲/镜像
3. **自动化**：`pytest tests/ -v`（含偏心圆弧重建回归测试，验证变换组合正确）

## 6. 历史教训（为什么这样做）

| 错误做法 | 问题 |
|---------|------|
| 在 `scan_to_xy` 里硬编码角度偏移 | 把安装姿态混进纯几何转换，换安装要改代码 |
| to_world 用轴重排 `(y,z,-x)` | det=-1 是**反射**（右手系变左手系），靠额外 90° 相位"凑"出看似对的结果 |
| mount_transform 恒等 | 忽略了棱镜 0° 参考相位，单帧弧 0° 指向竖直而非水平 |

正确架构：scan_to_xy 纯几何 + mount（棱镜相位，绕 z 90°）+ to_world（Ry90 横装，纯旋转），
全部变换 det=+1，每个自由度可独立配置。
